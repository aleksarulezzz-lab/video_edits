## Монтаж и вставки

**04 «Не копируй чужие видео»** (43.4 с с заставкой). Порядок: хук «Ютубу не нужно второе видео…» → структура и собственная позиция эксперта → анализ (глазами + нейросеть) → свой сценарий → финал «не копировать дословно». Оговорка «вопрос» и слово «Но» вырезаны.
- Хук: карточка видео и её «копия» с красным штампом «КОПИЯ».
- «Пузырь» вокруг лица со списком «в чужом видео смотрим: Структуру / Согласны ли вы как эксперт / Свой подход к проблеме».
- Плашки «об этом — в своём видео» ✓ и «своими глазами + нейросеть → свой сценарий».
- Плашка «вдохновляться коллегами — да».
- Финал в «пузыре»: перечёркнутые Ctrl+C → Ctrl+V и плашка «НЕ КОПИРУЙТЕ ДОСЛОВНО».
- Звуки: pop, click, whoosh на появлении графики.

**05 «Нейросеть не думает за тебя»** (62 с с заставкой). Убраны: «То есть финальное решение всегда оставляйте за собой» (повтор финала), «И также», оговорки «длинные» и повтор «сценариев, сценарий».
- Плашки «рутина → нейросеть» и «думать — по-прежнему вам».
- Три ✗: «нет структуры / тема не раскрыта / нет пользы».
- «Пузырь» со схемой «слабое исходное видео → 5 посредственных роликов».
- Три ✓: «Понятная тема / Польза / Понятный результат».
- Плашка «нейросеть смонтировала».
- «Пузырь» с цепочкой «ИИ помогает создать → Автор проверяет → Автор решает, публиковать ли».
- Финал: «аудитории непонятно?» → «докрутить с нейросетью / не публиковать».
- Дополнительная смена крупности на трёх границах фраз внутри длинного непрерывного куска.
